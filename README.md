# Personal Site

A lightweight personal portfolio website for me. It showcases who I am, what I work on, my skills, goals, and links to my projects and online profiles.

The site is intentionally simple and fast: a static HTML/CSS/JavaScript project with a responsive layout, a mobile navigation menu, and a light/dark theme toggle.

## Live Site

- https://assembakr00.github.io/Personal-Site

## Overview

This project acts as a digital home base for my work and interests and It includes:

- an introduction and short bio
- a skills section covering frontend, backend, and tools I use
- current projects and learning focus
- Hack Club and game jam experience
- long-term goals and personal interests
- links to GitHub, Boot.dev, X/Twitter, and itch.io

## Features

- Responsive personal website layout
- Side navigation menu for quick section access
- Light and dark theme toggle
- Clean static design with custom CSS styling
- Accessible buttons and menu controls
- Simple JavaScript interactions without any frontend framework
- Easy to customize for personal branding

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- GitHub Pages hosting

## Local Development

Because this is a static website, you can run it locally without installing dependencies.

### Option 1: Open directly

Open `index.html` in your browser or click this https://assembakr00.github.io/Zite

### Option 2: Use a local web server

From the project folder, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customization

You can easily update the site content by editing the relevant sections in `index.html`:

- intro/bio text
- skills and learning goals
- project descriptions
- social profiles
- footer text

To change the visual theme, edit the CSS variables in `main.css`.

To update interactions like the theme button or menu, edit `main.js`.

## Deployment

This project is designed for static hosting and is currently deployed through GitHub Pages.

If you want to deploy it again later:

1. Push the project to a GitHub repository
2. Enable GitHub Pages in the repository settings
3. Choose the branch and root folder for deployment

## Notes

This project is a personal portfolio and learning space, so it is intentionally simple and beginner-friendly. It is designed to be easy to maintain and expand as new projects, skills, and interests are added over time.
